# 체크메이트의 글꼴.

앱은 한국어와 영어에 Pretendard 가변 글꼴을 사용한다. 실행 중 외부 글꼴 서버에 접속하지 않고 앱에 포함된 WOFF2를 읽는다. 글꼴을 불러올 수 없을 때는 Segoe UI와 맑은 고딕 등 시스템 글꼴을 사용한다.

- 원본은 [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard)다.
- 가져온 소스 커밋은 `7aeb0698819be2b4097dae8ec8fe6a795e5cf3ae`다.
- 원본 파일은 `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`다.
- 앱 소스 파일은 `packages/desktop/src/renderer/글꼴/프리텐다드가변.woff2`다.
- SHA-256은 `9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4`다.
- 사용 조건은 SIL Open Font License 1.1이다. 원본 저작권과 라이선스 전문을 `packages/desktop/public/프리텐다드라이선스.txt`에 보관하며 Vite 빌드 결과에도 함께 복사한다.

글꼴 내용은 수정하지 않았다. 라이선스 파일을 제거하지 않고 설치 산출물에 함께 포함한다.
