# 체크메이트 개발 현황.

2026-09-25 기준 `0.1.0-alpha.1` 개발판이다. 로컬 폴더는 `C:/dev/E2E`, 설계 기준은 [구현 기준 설계](구현기준설계.md)와 [저장 및 연결 계약](저장및연결계약.md)이다. 모델 API를 호출하지 않으며 사람용 앱·CLI와 AI용 stdio MCP를 제공한다.

## 구현과 사용.

프로젝트의 세 JSON 원본을 등록하고 프로필의 명령·쓰기 범위를 확인한 뒤 승인한다. 실제 소스 지문이 바뀌면 기존 승인을 재사용하지 않는다. 서비스는 별도 Node 작업 프로세스의 종료와 소스·환경·증거·정리를 확인한 뒤 SQLite에 최종 판정을 저장한다. 같은 작업 경로는 하나씩, 서로 다른 프로젝트는 최대 두 개를 실행한다.

Electron 화면에서 등록·계획·승인·실행·취소·이력·근거를 확인한다. CLI와 MCP도 같은 결과를 읽는다. MCP는 사람 전용 등록·승인·기준 활성화·복구·수동 정리 확인을 노출하지 않는다. 요약은 UTF-8 8KiB 이내이고 상세는 페이지로 나눈다. 민감한 증거는 메타데이터만 반환한다.

| 기능 | 현재 동작과 시험 |
|---|---|
| 요구사항 완료 근거 | 선택 검사, 누락, 범위 밖, 코드 경로와 증거를 연결한다. 이번 프로필 밖의 필수 항목을 완료로 표시하지 않는다. |
| AI 수정 자료 | 기대·관측·위치·증거 ID와 보완 지침을 묶는다. 긴 내용은 축약과 생략 개수를 표시한다. |
| 정보 노출 검사 | 합성 표식의 DOM 및 명시적 API 응답 노출을 역할 정책과 대조한다. 표식 자체는 해시로 바꾼다. |
| 실제 검출력 검사 | Stryker를 실행한 강한 검사는 10개 검출, 약한 검사는 6개 검출과 4개 생존을 기록했다. 합성 권한 함수 범위다. |
| 디자인 위반 위치 | 실제 브라우저 규칙·접근성 관측과 공개 PNG의 해시를 확인하고 일치하는 캡처에 위반 위치를 표시한다. |
| 미검증 보완 이력 | 같은 공백을 중복 기록하지 않고 실제 관련 검사 통과에만 보완 실행을 연결한다. 관측한 실패와 미검증을 구분한다. |
| 이력과 자료 | 과거 보고서는 원래 상태를 보존하되 현재 통과로 재사용하지 않는다. HTML 내보내기, 체크섬 백업, 새 빈 폴더 복구를 제공한다. |
| 중단 복구 | 중단된 실행을 미확인으로 보존한다. 사람이 정리를 확인한 감사 기록을 남겨 새 실행을 허용할 수 있으며 과거 판정은 바뀌지 않는다. |
| 격리 시험 DB | 부모가 실행별 PostgreSQL의 생성 의도·정확한 ID·소유 라벨을 저장하고 종료 및 부재를 확인한다. 중단 뒤에는 사람의 해당 실행 선택 정리를 제공한다. |
| 설치 경로 | 동봉 Node와 SQLite, 고정 CLI 연결, 기본 자료 폴더, 설치·첫 검사·재시작·제거·같은 버전 재설치와 이력 보존을 실제 Windows에서 확인했다. 서명과 버전 간 업데이트는 후속 조건이다. |

[사용 안내](사용안내.md), [검사 작성 안내](검사작성안내.md), [검출력 사용법](검출력사용법.md), [개발 설치본](개발설치본.md)을 따른다. `npm test`는 빌드·타입·회귀, `npm run desktop:test`는 실제 Electron 흐름을 검사한다.

## 검증 근거와 현재 진행.

2026-09-25 제품 코드 `2161815`의 로컬 `npm test`에서 전체 빌드·타입 검사와 38파일 292개 시험이 통과했다. 환경별 시험 두 개는 건너뛰었다. 실제 Docker 수용에서 정상·실패·취소·부모 중단 후 선택 정리·생성 응답 유실·정리 실패 후 복구와 다른 소유 자원 보존을 확인했다. 합성 시험 자원의 잔존은 없었다. [격리 시험 DB](격리시험DB.md)에 실행별 근거를 기록한다.

확장 Electron 시험에서 등록부터 실제 실행과 결과, HTML 저장, 백업·복구, 가져온 이력, PNG 위반 위치와 오프라인 도움말이 통과했다. 검사한 1280/1920 화면과 100/150/200% 확대에서 가로 넘침과 자동 접근성 위반은 없었다. OS 파일 선택 결과는 시험용 경로로 고정했다. 구독 Codex CLI의 임시 MCP 연결에서는 프로젝트·기능·결과·요구사항 조회를 확인했다. API 키를 전달하지 않았고 기존 클라이언트 설정도 변경하지 않았다.

독립 검토에서 발견한 비정상 종료 판정, 지문 제외 실행 경로, 긴 한글 요약, 큰 PNG, 짧은 경로, 기존 ACL 변경 문제를 수정했다. 후속 격리 자원의 지연 생성·시간 제한·endpoint·마운트·복구 경계는 `c17cabd`에서 독립 재검토를 통과했다. 실제 화면 시험에서 추가로 확인한 Windows helper의 환경값 명령줄 전달은 `2161815`에서 길이 제한된 stdin 프레임으로 수정하고 실제 비노출·입력 손상·부모 종료 시험을 통과했다. 실제 설치 수용과 파일 대조 결과는 [설치 검증 기록](설치검증기록.md)에 있다.

합성 이력 1만 건과 개별 결과 10만 건의 실제 인증 통신에서 목록·상태·요약 p95는 각각 8.552ms·1.812ms·1.501ms였으며 응답 8KiB 제한을 지켰다. 측정 장비는 Windows 11, 16논리코어·31GiB이며 설계 기준인 4코어·16GB 장비의 결과는 아니다.

기반 단계는 [PR 2](https://github.com/yeunlee1/checkmate/pull/2)와 [PR 3](https://github.com/yeunlee1/checkmate/pull/3)으로 develop에 통합했다. 격리 DB와 실제 업무 연결은 [PR 4](https://github.com/yeunlee1/checkmate/pull/4)에서 추적한다. 초기 기반이나 독립 검토의 시험 수를 현재 전체 회귀와 합산하지 않는다.

## 실제 업무 연결과 출시 조건.

아틀리에의 독립 사본에서 빠른 검사 네 단계와 실제 PostgreSQL 및 업무 브라우저 연결을 확인했다. 실제 로그인·직원 승인·고객 등록·견적 초안 저장 및 API·화면 재조회 8단계가 통과했다. PostgreSQL은 실제 assertion 60개 통과와 기존 Node 전용 시험의 Worker 분기 1개 건너뜀을 보존해 전체 프로필을 `incomplete`로 남겼다. 원본 프로젝트와 기존 DB·서버·환경 파일은 변경하지 않았다. [아틀리에 연결 안내](아틀리에연결안내.md)에 각 프로필과 실제 실행 범위를 구분한다.

최신 서명 없는 개발 설치본은 깨끗한 `790bfa0`에서 제작했다. Windows 비밀 전달 수정이 포함됐으며 실제 설치 파일 4213개와 한글 경로 86개의 원본 해시 일치, 제거·같은 버전 재설치의 DB 보존을 확인했다. 설치된 앱과 동봉 Node로 실제 아틀리에 업무 8단계도 통과했다. Node가 설치되지 않은 깨끗한 Windows 장비의 수용과 버전 간 업데이트·실패 복구는 아직 남아 있다. 서명 자격과 정식 릴리스 승인은 별도 입력이다. 자동 업데이트·중단 자원의 추정 자동 회수·악성 프로젝트 샌드박스는 제공하지 않는다.

체크메이트의 로컬 개발 DB 변경과 검증 후 develop 병합은 승인됐으며 main 병합·공개 릴리스·실제 자료 변경은 이번 범위에 포함하지 않는다.
