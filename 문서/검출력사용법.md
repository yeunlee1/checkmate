# 실제 변이 검출력 예제 사용법.

`examples/검출력검증`은 CheckMate에 등록할 수 있는 독립적인 합성 Node 프로젝트다. `strong` 프로필은 허용과 거부 조건을 모두 검사하고, `weak` 프로필은 허용 조건만 검사한다. 두 프로필 모두 같은 `권한.mjs`를 Stryker 10으로 실제 변이 검사한다. `examples/대표검증`의 계산값 비교는 이 예제와 별개이며 변이 점수가 아니다.

## 준비와 실행.

대상 프로젝트가 `@stryker-mutator/core`, `@stryker-mutator/vitest-runner`, `vitest`를 직접 개발 의존성으로 준비해야 한다. CheckMate 설치 앱은 이를 다운로드하지 않는다. 저장소 예제는 루트 `node_modules`에 이미 설치된 개발 의존성을 사용한다. Stryker 실행 파일의 위치는 이 저장소 예제 구조를 기준으로 한다. 다른 프로젝트에 옮길 때는 그 프로젝트의 설치 경로에 맞춰 실행 진입점을 조정해야 한다.

로컬 서비스 또는 CLI에서 아래 순서로 진행한다. 각 프로필은 독립 계획과 사람의 승인을 사용한다.

```powershell
node packages/engine/dist/명령.js register examples/검출력검증 --trust
node packages/engine/dist/명령.js inspect --project e2e2c580-475a-4cb5-94e7-1e9a87e0794e --profile strong
node packages/engine/dist/명령.js approve --plan <계획 ID> --fingerprint <계획 지문> --confirm
node packages/engine/dist/명령.js run --project e2e2c580-475a-4cb5-94e7-1e9a87e0794e --plan <계획 ID> --request-id <새 UUID> --wait
```

`weak`도 `inspect --profile weak`부터 새 계획으로 반복한다. 등록된 명령의 제한 시간은 프로필당 120초이며 실제 통합 시험은 두 실행을 합쳐 최대 180초를 허용한다. Stryker 동시성은 1로 고정한다.

## 결과와 경계.

2026-09-25 Windows 합성 통합 시험에서는 강한 검사가 `Killed 10`, `Survived 0`, 점수 `10/10`, 제품 판정 `passed`였고 약한 검사는 `Killed 6`, `Survived 4`, 점수 `6/10`, 제품 판정 `failed`였다. 실행마다 변이 보고서를 읽어 다시 확인해야 하며 이 수치를 다른 대상 프로젝트의 결과로 사용하지 않는다.

명령의 표준 출력에는 리포터의 NDJSON 사건만 기록한다. Stryker 출력은 별도로 수집해 `restricted` 로그 증거에 저장한다. `public` 증거에는 합성 자료에서 정규화한 변이 보고서만 기록하며 원본 코드, 대체 코드, Stryker 원본 보고서는 포함하지 않는다. 증거에는 바이트 길이와 SHA256이 붙고 부모 실행기가 다시 검사한다. 수정 자료 묶음에는 살아남은 변이의 파일과 줄, 검사 기대값, 변이 점수 요약이 남는다.

Stryker는 각 실행에서 `examples/검출력검증/.runtime/<실행 UUID>`에 합성 소스 복사본과 임시 파일을 만든다. 원본 소스의 바이트 해시와 제품 소스 지문은 실행 전후 비교한다. 정상 종료 시 소유 표식을 확인한 자기 UUID 폴더만 지우며 다른 작업 폴더는 보존한다. Node 자식은 `shell: false`로 실행하고 Windows에서는 부모 실행기의 JobObject에 남는다. 취소나 시간 초과 때 부모 실행기가 프로세스 정리를 판정하며, 강제 종료 뒤 남은 임시 폴더는 소유권을 확인하기 전까지 임의로 지우지 않는다.

어댑터는 `Survived`와 `NoCoverage`를 실패로, `Timeout`, 오류, 미실행, 승인되지 않은 `Ignored`를 미검증으로 유지한다. 변이 점수에 `Timeout`이 들어가더라도 통과로 바꾸지 않는다. 이 예제는 합성 권한 함수와 제품 실행 연결만 검증한다.

좁은 회귀 시험은 다음 명령으로 실행한다.

```powershell
npx vitest run tests/검출력연결.test.ts tests/검출력검사.test.ts tests/검사실행기.test.ts
```
