# 업데이트와 AI 연결.

설정의 **업데이트 확인**은 새 버전 정보만 조회한다. AI가 연결되어 있거나 검사가 실행 중이어도 확인할 수 있으며, 이 버튼으로 설치 파일을 내려받거나 검사를 중단하지 않는다.

0.2.1 공개 업데이트 목록의 선두 UTF-8 BOM 때문에 조회가 실패하는 문제가 확인됐다. 0.2.2는 정상 선두 BOM을 읽을 수 있고, 새 배포 목록은 제작 지문을 계산하기 전에 BOM을 제거한다. 이 보완은 목록의 인코딩 호환성을 해결하며 실제 요청의 수명 문제와는 구분한다. 이미 공개한 파일은 교체하지 않는다.

0.2.1과 0.2.2에는 Electron의 요청 스트림 `close`를 응답 실패로 처리해 정상 응답 전에 요청을 취소하는 문제도 있다. 0.2.3은 실제 응답의 완료와 중단을 구분한다. 응답이 없으면 기존 전체 15초 제한으로 실패하며, HTTPS 주소·리디렉션·본문 크기·문자 검증은 유지한다. 배포 검사에도 실제 Electron과 격리 서버를 사용하는 요청 시험을 포함한다.

새 버전이 있으면 **다운로드**를 선택한다. 앱은 같은 설치본에 등록된 자료 폴더의 실행과 정리 상태를 확인하고, 서비스를 강제로 종료하지 않고 유휴 종료를 기다린다. 실행 중이거나 정리 상태와 연결 소유권을 확인할 수 없으면 업데이트를 보류한다. 준비된 설치 파일은 **재시작하여 업데이트**로 적용한다.

## 관리형 AI 연결.

설치 앱의 설정에서 제공하는 MCP 실행 정보를 AI 도구에 한 번 등록하면 관리형 연결을 사용한다. 실행 명령은 사용자 자료 폴더 안에 복사한 전용 Node를 가리키므로 PC에 별도 Node를 설치할 필요가 없다. 폴더 경로를 다른 PC에 그대로 복사하지 말고, 각 PC의 설치 앱이 표시하는 실행 정보를 사용한다.

관리형 연결은 업데이트 중에도 AI 도구와의 통신을 유지한다. 업데이트 중 새 도구 요청에는 준비 중 상태를 반환하고, 업데이트가 끝난 뒤 다음 요청에서 새 버전의 검사 서비스에 연결한다. 업데이트 전 요청을 자동으로 다시 보내지 않는다.

버전이 올라간 업데이트 뒤에는 새 AI 연결 세션이 만들어진다. 이전 검사 기록은 그대로 읽을 수 있지만 이전 실행의 제어 권한을 새 세션이 자동으로 넘겨받지는 않는다. 같은 버전의 서비스가 비정상적으로 재시작된 경우에도 기존 자격을 자동 재발급하지 않는다. 이 경우 읽기 조회와 실행 제어가 서로 다른 상태일 수 있으며, 앱이 표시하는 재연결 또는 사람의 인계 절차를 따른다.

관리형 연결이 유지하는 도구 목록은 처음 시작한 연결 프로그램의 범위다. 새 버전에서 도구 계약 자체가 바뀌면 AI 도구에서 정상적으로 연결을 다시 시작해야 할 수 있다. 기존 `mcp` 명령의 자격 정책은 그대로 유지한다.

## 0.1.0에서 처음 전환할 때.

0.1.0의 업데이트 확인은 다운로드와 묶여 있어 AI 연결 또는 같은 설치본의 엔진 때문에 보류될 수 있다. 처음 한 번은 새 설치본으로 별도 전환하고 AI 도구의 MCP 실행 정보도 바꿔야 한다. 설치 앱만 바꿔도 개발 폴더의 CLI를 가리키는 AI 설정이 자동으로 수정되지는 않는다.

1. 진행 중인 검사와 정리 미확인 자료를 확인하고 앱에서 현재 자료를 백업한다. 백업 검증과 기존 경로를 기록한다.
2. 앱과 해당 연결을 정상 종료하고 서비스의 유휴 종료를 확인한다. 다른 세션의 프로세스와 불명확한 잠금을 강제로 제거하지 않는다.
3. 필요한 기존 저장 구조 이행은 백업이 검증된 같은 자료 폴더에 명시적으로 수행한다. 실패 또는 미확인 결과를 지우거나 다시 실행하지 않는다.
4. 검증된 새 설치본을 설치하고 설정에 표시되는 관리형 MCP 명령으로 해당 AI 연결 항목만 바꾼다. 이전 설정은 되돌릴 수 있게 보관한다.
5. AI 도구의 정상 재연결 기능 또는 새 세션에서 실제 서비스 버전과 자료 경로를 확인한다. 프로젝트와 기존 실행 기록이 보존됐는지도 확인한다.

이후의 관리형 업데이트와 이 최초 전환은 별도 절차다. 설치 및 코드 시험 통과만으로 현재 사용자의 AI 연결까지 전환됐다고 판단하지 않는다.

## 0.2.1과 0.2.2의 조회 오류에서 전환할 때.

기존 앱의 조회 코드가 실패하면 새 공개 목록만으로 자동 업데이트를 시작할 수 없다. 현재 자료 백업과 검사·정리의 유휴 상태를 확인하고 검증된 새 설치본으로 별도 전환한다. 이미 관리형 연결을 사용한다면 기존 연결 명령을 버전 숫자만 보고 다시 바꾸지 않는다. 새 앱의 버전과 자료 위치, 같은 AI 연결에서 새 검사 서비스와 기존 이력을 실제로 확인한다.
